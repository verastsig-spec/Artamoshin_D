Random Task Generator

**Автор:** [Данил Артамошин]

Описание
Приложение на Python с графическим интерфейсом (Tkinter), которое помогает бороться с нерешительностью, выбирая случайную полезную задачу из списка. 

Функции:
- Генерация случайной задачи одним кликом.
- Категории: Учёба, Спорт, Работа.
- Фильтрация истории по категориям.
- Автоматическое сохранение истории в JSON-файл.

Использование
1. Запустите `main.py`.
2. Нажмите кнопку "Сгенерировать задачу".
3. Используйте выпадающий список для фильтрации выполненных дел.
